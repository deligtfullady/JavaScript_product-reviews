**Урок 3. Промисы. Хранилище**

---

## Цель работы

Создать интерактивную веб-страницу для оставления и просмотра отзывов о продуктах.

Пользователи могут:
- добавлять отзывы о различных продуктах;
- просматривать список продуктов и все отзывы по каждому из них;
- удалять отдельные отзывы.

Все данные сохраняются в **LocalStorage** и не теряются при перезагрузке страницы.

- [x] Поле для ввода названия продукта

- [x] Список всех продуктов, о которых есть отзывы

- [x] Кнопка «Удалить» рядом с каждым отзывом

## Что демонстрирует работа

| Тема урока          | Как реализовано                                      |
|---------------------|------------------------------------------------------|
| **Промисы**         | `loadReviews()` и `saveReviews()` возвращают Promise |
| **async/await**     | Используется при добавлении и удалении отзывов       |
| **LocalStorage**    | Все отзывы хранятся в браузере между сессиями         |
| **JSON**            | `JSON.parse` / `JSON.stringify` для работы с данными |
| **DOM**             | Динамическое создание списка продуктов и отзывов     |
