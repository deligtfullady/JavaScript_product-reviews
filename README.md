# Product Reviews — Отзывы о продуктах

Веб-приложение по курсу **«Продвинутый JavaScript»**  
**Урок 3. Промисы. Хранилище**

---

## Цель работы

Создать интерактивную веб-страницу для оставления и просмотра отзывов о продуктах.

Пользователи могут:
- добавлять отзывы о различных продуктах;
- просматривать список продуктов и все отзывы по каждому из них;
- удалять отдельные отзывы.

Все данные сохраняются в **LocalStorage** и не теряются при перезагрузке страницы.

## Как работает LocalStorage + Промисы

Все операции с хранилищем обёрнуты в **промисы**:

```js
function loadReviews() {
  return new Promise((resolve, reject) => {
    try {
      const raw = localStorage.getItem('product_reviews');
      const data = raw ? JSON.parse(raw) : {};
      resolve(data);
    } catch (err) {
      reject(err);
    }
  });
}

function saveReviews(data) {
  return new Promise((resolve, reject) => {
    try {
      localStorage.setItem('product_reviews', JSON.stringify(data));
      resolve();
    } catch (err) {
      reject(err);
    }
  });
}
```

Добавление и удаление выполняются через `async/await`:

```js
async function addReview(productName, text) {
  const data = await loadReviews();
  // ... изменение данных
  await saveReviews(data);
}
```

## Запуск

1. Откройте файл `index.html` в браузере  
   (можно двойным кликом или через Live Server в VS Code)

2. Переключайтесь между вкладками:
   - **Добавить отзыв** — форма
   - **Просмотр отзывов** — список продуктов и отзывов

> LocalStorage работает и при открытии через `file://`,  
> дополнительный сервер не обязателен.

## Что демонстрирует работа

| Тема урока          | Как реализовано                                      |
|---------------------|------------------------------------------------------|
| **Промисы**         | `loadReviews()` и `saveReviews()` возвращают Promise |
| **async/await**     | Используется при добавлении и удалении отзывов       |
| **LocalStorage**    | Все отзывы хранятся в браузере между сессиями         |
| **JSON**            | `JSON.parse` / `JSON.stringify` для работы с данными |
| **DOM**             | Динамическое создание списка продуктов и отзывов     |
